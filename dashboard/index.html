How the ranking works. For every category, the radar learns a market-cap-to-TVL multiple from the protocols in the snapshot that already have a token (category median, shrunk toward the global median when samples are few). A pre-token protocol's implied value is its TVL × its category multiple × a momentum factor from its 7-day TVL change × a maturity factor from how long it has been tracked. The model is rebuilt from the snapshot on every run — no hand-kept list — so a protocol that appears in tomorrow's data is ranked the moment it exists.

Implied value is a model's estimate, not a promise: most pre-token protocols launch lower, later, or never. Farm with money you can afford to strand.
